# I want an operating system

If you want one operating system that is easy to use and also runs well in an emulator, choose:

## Ubuntu 24.04 LTS

Why this is a good default:
- Easy for beginners
- Stable and reliable
- Large community and lots of tutorials
- Good support for programming tools
- Runs well in emulators like VirtualBox, VMware, and QEMU

## Emulator setup (recommended)
- Download: **Ubuntu Desktop 24.04 LTS ISO**
- VM CPU: **2 cores minimum** (4 is better)
- VM RAM: **4 GB minimum** (8 GB recommended)
- VM Storage: **25 GB minimum**
- Turn on hardware virtualization in BIOS/UEFI (**Intel VT-x / AMD-V**)

## Other options
- **Windows 11**: good for gaming and general use, but heavier in a VM
- **Fedora Workstation**: newer packages, good developer experience
- **Linux Mint**: very beginner-friendly Linux desktop
